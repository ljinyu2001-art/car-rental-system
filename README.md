# 汽车租赁查询系统

基于 **FastAPI + MySQL + Vue3** 开发的汽车租赁查询系统。

本系统实现用户注册、用户登录、车辆信息查询、车辆搜索筛选以及车辆预约等功能。

项目采用前后端分离架构：

- 前端：Vue3 + Vite + Element Plus
- 后端：FastAPI
- 数据库：MySQL

---

## 一、项目介绍

汽车租赁查询系统主要用于模拟汽车租赁业务流程。

用户可以通过系统：

1. 注册账号
2. 登录系统
3. 查询车辆信息
4. 根据条件搜索车辆
5. 筛选不同类型车辆
6. 预约车辆


系统采用 RESTful API 设计，实现前后端数据交互。
